# Wallpaper gallery

Every image the Rainmeter slideshow widget cycles through.

Provenance and licence notes for each are in [ATTRIBUTION.md](../ATTRIBUTION.md) — several
are public-domain artworks, several are collected wallpapers with no identified author.

To use your own instead, edit `PicturesFolder` in
`Documents\Rainmeter\Skins\BigSur\Widgets\Slideshow\UserVariables.inc` and refresh the skin.
